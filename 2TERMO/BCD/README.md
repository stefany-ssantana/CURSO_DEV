## 📌 Sobre o Módulo

Esta pasta contém os scripts e exercícios focados em **Banco de Dados Relacional**, cobrindo desde a criação de schemas e tabelas até a manipulação avançada de dados.

### 🛠️ Conteúdos e Conceitos Aplicados

* **DDL (Data Definition Language):** `CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE`, `RENAME`.
* **DML (Data Manipulation Language):** `INSERT`, `UPDATE`, `DELETE`, `SELECT`.
* **Restrições de Integridade:** `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `NOT NULL`, `DEFAULT`, `ENUM`.
* **Projetos Práticos:** Modelagem de banco de dados para oficina mecânica e outros sistemas.

---

## 🚀 Como Executar os Scripts

1. Certifique-se de ter o **MySQL Workbench** ou outro SGBD de sua preferência instalado.
2. Abordo qualquer um dos arquivos `.sql` presentes nesta pasta.
3. Execute o script sequencialmente no seu ambiente SQL.
