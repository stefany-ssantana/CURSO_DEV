## 📌 Sobre o Módulo

Repositório dedicado ao aprendizado de criação de interfaces visuais para a web, com foco em semântica, acessibilidade, responsividade e experiência do usuário (UX/UI).

### 🛠️ Recursos Utilizados

* **HTML5:** Estruturação semântica de páginas web.
* **CSS3:** Layouts modernos com Flexbox, CSS Grid, variáveis e animações.
* **Design Responsivo:** Media Queries e adaptação para dispositivos móveis (Mobile First).
* **JavaScript:** Interatividade na interface e manipulação da DOM.

---

## 🖥️ Como Visualizar as Páginas

1. Clone o repositório ou navegue até a pasta desejada.
2. Abra o arquivo `index.html` diretamente em qualquer navegador, ou utilize a extensão **Live Server** no VS Code para rodar localmente.
