## 📌 Sobre o Módulo

Projetos e exercícios práticos focados no desenvolvimento server-side, integrando a lógica de aplicação com bancos de dados e servindo rotas para o front-end.

### 🛠️ Tecnologias e Conceitos

* **Linguagem/Runtime:** Node.js / JavaScript ES6+
* **Arquitetura:** Padrão MVC (Model-View-Controller) / RESTful APIs
* **Conectividade:** Integração com banco de dados MySQL
* **Protocolo HTTP:** Métodos GET, POST, PUT, DELETE e tratamento de requisições/respostas.
